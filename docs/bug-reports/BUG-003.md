# BUG-003 Duplicate Order Validation Accepted

## Summary

The same order can be validated repeatedly, increasing the validation count and potentially creating duplicate business events downstream.

## Severity

Critical

## Steps to Reproduce

1. Submit a valid validation request for order O1001.
2. Submit exactly the same request again.

## Expected

The first request returns 200. The second request returns 409 `DUPLICATE_REQUEST`.

## Actual

Both requests return 200.

## Root Cause

The service incremented `validated_count` without checking whether the order had already been validated.

## Fix

Reject validation when `validated_count > 0`.

## Regression

`TC-API-010 / duplicateValidationIsRejected` passes on `v1.0-fixed`.
