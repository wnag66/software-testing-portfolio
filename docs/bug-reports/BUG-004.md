# BUG-004 Zero Page Size Returns 500

## Summary

Requesting an event page with `size=0` triggers an internal arithmetic error.

## Severity

High

## Steps to Reproduce

1. Call `GET /api/v1/events?page=1&size=0`.

## Expected

The request returns 400 `INVALID_REQUEST`.

## Actual

The request returns 500 `INTERNAL_ERROR`.

## Root Cause

The service computed `total / size` without validating that size was positive.

## Fix

Validate `size` in the range 1 to 50 before calculating pagination.

## Regression

`TC-API-017 / zeroPageSizeIsRejected` passes on `v1.0-fixed`.
