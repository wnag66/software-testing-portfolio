# BUG-005 Oversized Page Size Accepted

## Summary

The API accepts a page size above the documented maximum and can return more records than clients expect.

## Severity

Medium

## Steps to Reproduce

1. Call `GET /api/v1/events?page=1&size=51`.

## Expected

The request returns 400 `INVALID_REQUEST`.

## Actual

The request returns 200 with more than 50 records.

## Root Cause

The service validated the lower boundary but ignored the maximum allowed page size.

## Fix

Enforce a maximum page size of 50.

## Regression

`TC-API-018 / oversizedPageSizeIsRejected` passes on `v1.0-fixed`.
