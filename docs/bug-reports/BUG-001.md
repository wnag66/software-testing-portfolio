# BUG-001 Negative Heartbeat Latency Accepted

## Summary

The API accepts a negative `latencyMs` value and persists it as device health data.

## Severity

High

## Steps to Reproduce

1. Start the buggy version.
2. Send `POST /api/v1/devices/D001/heartbeat`.
3. Use `latencyMs: -1`.
4. Query device D001.

## Expected

The request returns 400 `INVALID_REQUEST` and the stored device state is unchanged.

## Actual

The request returns 200 and stores the negative latency.

## Root Cause

Input validation checked status and device existence but omitted the latency lower bound.

## Fix

Reject negative latency in `DeviceService` before persistence.

## Regression

`TC-API-006 / negativeHeartbeatLatencyIsRejected` passes on `v1.0-fixed`.
